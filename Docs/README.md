# Vision: 

* Название проекта: Tracker 

* Цель проекта и целевая аудитория: 
Ключевой целью проекта является отслеживание времени затраченного на ту или иную задачу, поставленную тем или иным лицом. Программа базируется на экранном времени пользователя, который, к примеру, работает на удалёнке, либо на каком-то-либо предприятии, где важно вести отчётность по часам 

* Проблема, которую решает система:
Халатность рабочего класса/процесса
